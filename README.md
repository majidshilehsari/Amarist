# آماریست (Amarist)

سرویس آنلاین **تحلیل آماری داده‌های پژوهشی** و **تولید داده‌های تمرینی هدفمند** برای اساتید آمار و روش تحقیق.

اساتید در حین درس‌دادن برای پیدا کردن داده‌های تمرینی‌ای که دانشجوها با کار روی آن‌ها به نتایجِ مشابه برسند، گرفتارند. آماریست این دو سرویس را کنار هم می‌گذارد:

1. **تحلیل داده‌های واقعی** — وارد کردن داده (اکسل، CSV یا دستی) و دریافت تحلیل آماری و گزارش قابل‌ارائه.
2. **تولید داده‌های تمرینی هدفمند** — تعیین سناریو و پارامترهای آماری و تولید داده‌ی تمرینی شبیه‌سازی‌شده به‌همراه کلید پاسخ برای استاد.

## حالت‌های پژوهشی

| دسته | حالت‌ها |
| --- | --- |
| پژوهش‌های مداخله‌ای (کارآزمایی بالینی) | اثربخشی یک درمان · مقایسه اثربخشی دو درمان |
| پژوهش‌های مدل‌سازی | معادلات ساختاری (SEM) · پیش‌بینی رگرسیونی |

## ویژگی‌ها

- بدون دیتابیس و بدون ثبت‌نام — ذخیره‌سازی در مرورگر (localStorage)
- خروجی اکسل، ورد و CSV و بکاپ داده‌ها
- داده‌ها از مرورگر خارج نمی‌شود (حریم خصوصی داده‌های پژوهشی)

## تکنولوژی

- [Next.js](https://nextjs.org) (App Router) — نسخه ۱۶
- TypeScript
- Tailwind CSS v4
- فونت وزیرمتن (self-hosted)
- آماده‌ی استقرار روی [Vercel](https://vercel.com)

## توسعه

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # بیلد تولید
npm run lint     # بررسی کد
```
